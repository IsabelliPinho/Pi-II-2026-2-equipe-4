# Gabi Cake — Documentação do Projeto

Este repositório reúne os documentos e artefatos produzidos durante o levantamento e a organização dos requisitos do sistema da Gabi Cake, uma loja de bolos e outras massas. O projeto tem como objetivo facilitar a organização dos pedidos, dos clientes e dos prazos de entrega ou retirada, além de disponibilizar acesso à planilha utilizada para o controle financeiro da loja.

## Documentação dos requisitos

Nesta seção estão reunidos os documentos relacionados aos requisitos do sistema e ao seu funcionamento.

- **[Documento de Requisitos](https://github.com/IsabelliPinho/Pi-II-2026-2-equipe-4/blob/main/docs/Documento%20de%20Requisitos.pdf):** Apresenta os requisitos funcionais e não funcionais definidos para o sistema.
- **[Regras de Negócio](https://github.com/IsabelliPinho/Pi-II-2026-2-equipe-4/blob/main/docs/Documento%20de%20Requisitos.pdf):** Reúne as regras que devem ser respeitadas durante o funcionamento do sistema.
- **[Critérios de Aceitação](https://github.com/IsabelliPinho/Pi-II-2026-2-equipe-4/blob/main/docs/Documento%20de%20Requisitos.pdf):** Descreve as condições utilizadas para verificar se cada requisito atende ao que foi definido.
- **Matriz de Rastreabilidade:** Relaciona os requisitos funcionais aos casos de uso, às telas, às rotas, às regras de negócio e às issues do projeto.

## Casos de uso e interface

Esta seção reúne os artefatos que ajudam a entender como o sistema será utilizado e como suas funcionalidades serão organizadas.

- **Casos de Uso:** Apresenta as interações entre a gerente e as funcionalidades do sistema.
- **Telas e Protótipos:** Reúne as representações das telas planejadas para o sistema.
- **Rotas do Sistema:** Documenta as rotas relacionadas às funcionalidades disponíveis.

## Planilha financeira

- **Documentação da Planilha Financeira:** Explica a utilização da planilha externa de controle financeiro, incluindo sua finalidade e a organização das informações.

## Acompanhamento do projeto

- **[Issues](https://github.com/IsabelliPinho/Pi-II-2026-2-equipe-4/issues):** Reúne as tarefas, os problemas identificados e as atividades registradas durante o desenvolvimento do projeto.

## Organização dos documentos

Os artefatos estão organizados por assunto para facilitar a localização e a consulta das informações. Conforme o projeto avança, os documentos podem ser atualizados para acompanhar as mudanças nos requisitos e nas demais partes do sistema.
