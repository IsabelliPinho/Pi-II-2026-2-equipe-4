# Matriz de Rastreabilidade

A Matriz de Rastreabilidade da Gabi Cake tem como objetivo facilitar o acompanhamento dos requisitos do sistema e suas relações com os casos de uso, as telas e rotas, as regras de negócio e as issues do projeto. Dessa forma, é possível verificar como cada parte do sistema está relacionada às demais, contribuindo para a organização e a manutenção da documentação.
